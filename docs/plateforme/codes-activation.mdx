title: "Codes d'activation"
description: "Ce que le code d'activation fait, et ne fait pas."
---

Chaque ecole recoit un **code d'activation** unique des son inscription sur [saas.ardoiseeduc.com](https://saas.ardoiseeduc.com/register).

## A quoi il sert

C'est le seul moyen pour votre installation de se faire connaitre de la Plateforme : sans lui, votre serveur ne peut pas recevoir les demandes du marketplace (inscriptions, candidatures), synchroniser vos classes, ni envoyer de notifications WhatsApp.

<Warning>
  Le code d'activation identifie votre ecole aupres de la Plateforme - il n'a jamais accorde et n'accorde
  aujourd'hui aucune fonctionnalite payante : le logiciel Ardoise est gratuit dans son integralite (voir
  [Abonnement et tarifs](/plateforme/abonnement)).
</Warning>

## Ou le retrouver

Toujours affiche sur votre tableau de bord fondateur, dans le guide d'installation. Voir [Installation](/guide-technique/installation) pour l'utiliser lors de la configuration de votre serveur.

## Verification periodique

Votre installation revalide periodiquement ce code aupres de la Plateforme. En cas de coupure internet, une periode de grace (par defaut 14 jours) evite toute interruption le temps que la connexion revienne.
