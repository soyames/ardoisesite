---
title: "Questions fréquentes"
description: "Reponses aux questions les plus courantes du personnel de l'ecole."
---

<AccordionGroup>
  <Accordion title="Ardoise fonctionne-t-il sans connexion internet ?">
    Oui pour l'usage quotidien - votre serveur tourne sur votre propre reseau. Une connexion internet reste necessaire pour la synchronisation de licence, l'envoi de notifications WhatsApp, et l'acces a distance eventuel.
  </Accordion>
  <Accordion title="Qui peut voir les donnees de mon ecole ?">
    Uniquement le personnel a qui vous avez attribue un role. La Plateforme centrale ne stocke jamais les dossiers eleves, les notes ou les paiements de scolarite - ces donnees restent sur le serveur de votre ecole.
  </Accordion>
  <Accordion title="J'ai perdu mon code d'activation, que faire ?">
    Reconnectez-vous en tant que fondateur/fondatrice sur le portail SaaS - votre code d'activation y est toujours affiche.
  </Accordion>
  <Accordion title="Puis-je changer d'ordinateur/serveur plus tard ?">
    Oui - le dossier de donnees se copie tel quel sur la nouvelle machine (voir le [guide d'installation](/guide-technique/installation)).
  </Accordion>
  <Accordion title="Un role peut-il faire plus que ce qui est decrit ici ?">
    Chaque role a un perimetre precis (voir [Premiers pas](/guide-utilisateur/premiers-pas)). Si une action semble bloquee sans raison apparente, verifiez d'abord le role attribue avant de considerer cela comme un bug.
  </Accordion>
</AccordionGroup>

Une question sans reponse ici ? Consultez le [guide technique](/guide-technique/depannage) ou contactez le support.
